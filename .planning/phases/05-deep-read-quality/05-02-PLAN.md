# Phase 5 Plan 02: 歌词回退链路与缺失项修复

## Objective

保证 READ-03：歌词展示路径正确；META-03：`shang-bu-liao` 占位不再伪装成完整内容。

## Tasks

### Task 1 — Lyrics loading correctness

In `lib/content/index.ts` (and page if needed):

1. When loading deep-read, prefer `raw-lyrics/{slug}.txt`.
2. If raw lyrics text is placeholder-like (`待补录`, `待补充`, empty), treat as **no full lyrics** (do not surface as `fullLyrics`).
3. Same for frontmatter `fullLyrics`.
4. Filter `lyricBlocks` / interpretation `lyricText` that are placeholder stubs.

### Task 2 — Song page UX for missing lyrics

In `app/songs/[slug]/page.tsx`:

1. Only show “完整歌词” section when `fullLyrics` is non-placeholder.
2. Optionally show a short muted note when deep-read exists but lyrics pending (Chinese, consistent style).

### Task 3 — shang-bu-liao content fix

1. Prefer real UTF-8 lyrics in `content/songs/raw-lyrics/shang-bu-liao.txt` if a verified source is available in-repo or known catalog; **do not invent** random lines.
2. If real full lyrics cannot be verified, keep file as explicit placeholder BUT ensure UI does not claim completeness; remove fake `lyricText: 开场句/中段句` units from deep-read or mark so sanitize drops them.
3. Update `docs/ISSUES-LOG.md` status accordingly (open with better description, or closed if real lyrics landed).

### Task 4 — Tests

1. Test sanitize/index behavior for placeholder raw lyrics → no fullLyrics.
2. Test interpretation filter drops scaffold units.
3. Keep `npm test` / `npm run typecheck` green.
