# Phase 5 Plan 01: deep-read 结构化精修与标签一致性

## Objective

建立 deep-read 质量度量，过滤 scaffold 展示噪声，并对高优先曲目做第一批结构化精修。

## Tasks

### Task 1 — Scaffold detection + quality report

1. Expand scaffold/placeholder markers in `scripts/config/audit-rules.mjs` and `lib/content/sanitize.ts` PLACEHOLDER_MARKERS (include: `自动补充的第`, `情绪结构样本`, `待补录`, `语句 5`, `开场句` when used as lyricText stubs, `基础深读`).
2. Add `scripts/report-deepread-quality.mjs` that:
   - scans `content/songs/deep-reads/*.md`
   - classifies each as `scaffold` | `passable` | `editorial`
   - flags missing `mvUrl`, empty/weak `lyricInterpretations`
   - joins with `content/songs/index.json` for favoriteLevel/tags
   - writes `docs/DEEPREAD-QUALITY-REPORT.json` + `.md`
3. Add npm script `report:deepread-quality`.
4. Optionally tighten `scripts/audit-deepread-style.mjs` / content issue rules to use same markers.

### Task 2 — Priority editorial batch (≥4 of 8 high favorites)

For at least these (prefer all 8 if time): `tian-hei-hei`, `yu-jian`, `wo-huai-nian-de`, `ni-guang`, `shang-hao-de-qing-chun`, `ke-bu-le`, `shi-shi-hou`, `tiao-wu-de-fan-gu`:

1. Read matching `raw-lyrics/{slug}.txt` and current deep-read.
2. Rewrite `lyricInterpretations` to be **unique per section**, anchored to real lyric lines (not template “这一句的价值在于…” spam).
3. Ensure body overview is not “情绪结构样本” boilerplate; write song-specific overview.
4. Keep/fill `songDesign` with song-specific structure notes.
5. Keep existing valid `mvUrl` if present; do not invent fake bilibili/youtube IDs. If missing, leave empty rather than fabricate.
6. Align `summary` / moodTags / themeTags in `content/songs/index.json` lightly if clearly inconsistent with the rewrite (META-02 for this batch only).

### Task 3 — Tests

1. Unit tests for new sanitize markers (`isPlaceholderLikeText` catches scaffold phrases).
2. Optional: smoke that report script exits 0.

## Verification

```bash
npm run report:deepread-quality
npm test
npm run typecheck
```

## Acceptance

- [ ] Quality report exists and shows high-favorite tiers
- [ ] ≥4 high-favorite deep-reads free of `自动补充的第` / `情绪结构样本`
- [ ] Sanitize treats scaffold phrases as placeholder-like
- [ ] Tests pass
