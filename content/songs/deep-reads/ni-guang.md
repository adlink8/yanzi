lyricInterpretations:
  - id: unit-01
    section: 害怕答案
    reference: 风里打转
    lyricText: 也许我一直害怕有答案 / 也许爱静静在风里打转
    interpretation: >-
      开场不是口号式励志，而是承认犹豫：害怕答案、爱在风里打转、释怀短暂又重来、自问自答。
      低音区的毛边感让“不勇敢”先成立，后面的奔跑才有重量。逆光之所以动人，正因为先写够了阴影里的拉扯。
    whyItMatters: 建立写实地基——光不是开局自带，而是从不确定里挣出来的。
  - id: unit-02
    section: 推开仍留下
    reference: 困难与遗憾
    lyricText: 用力推开你我依然留下 / 遗憾没有到达
    interpretation: >-
      “我不要困难把我们挤散”是意志，“责备自己不勇敢”是内疚；拥抱过还害怕，推开了却还在。
      这段把亲密关系写成一种进退失据：既怕靠近，又无法真正抽身。遗憾不是没爱过，而是没抵达。
    whyItMatters: 中段张力来自矛盾动作本身，而不是外部反派。
  - id: unit-03
    section: 逆着光
    reference: 泪光那力量
    lyricText: 我逆着光却看见 / 那是泪光那力量 / 面对希望逆着光
    interpretation: >-
      物理上的逆光刺眼甚至痛苦，精神上却是主动选择面向光源。泪光在这里不是示弱道具，而是被希望
      点燃后的能量标记。“不想再去抵挡”是转折：停止与希望角力，允许自己被照到。
      编曲的推进感在此段最明显，像在荒野里加速。
    whyItMatters: 写出“能量歌后”内核：光在迎光者脸上，不在遥远口号里。
  - id: unit-04

    reference: 睁开眼
    lyricText: 睁开眼打开窗 / 才发现你就是光芒
    interpretation: >-
      背对时漆黑，睁眼开窗后才确认“你就是光芒”——这个“你”可以是爱人，也可以是未放弃的自己

    whyItMatters: 把逆光从姿态落实为认出光源，全曲命题闭环。

《逆光》最动人的地方，不是在最好的状态里发光，而是在不那么容易的时候还选择面向希望。它先允许你害怕答案、推开又留下、背对时一片漆黑，然后才说：泪光也可以是力量。

燕姿在这里唱的不是虚假鸡汤，而是一种可执行的转向——停止抵挡，逆着光也继续走。对很多在低谷里需要节奏把自己带起来的人来说，这首歌至今仍像一束刺眼却必要的光源。
