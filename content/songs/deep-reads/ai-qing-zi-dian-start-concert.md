lyricInterpretations:
  - id: part-01
    section: 学会语言却丢了世界
    reference: 爱情的语言
    lyricText: 我已经学会爱情的语言 可是却失去你我的世界
    interpretation: >-
      开场就是悖论：语言学会了，世界却丢了。沟通技巧、暗示、规则全练过，关系本体仍保不住。
      现场版唱这句时，像把“学霸型失恋”摊在灯光下——越努力越显得失落荒诞。
      它与同场《爱情证书》的“为爱还在学”形成对照：证书信学习能毕业，字典承认学完仍可能交白卷。
    whyItMatters: 全曲“字典”隐喻的起点：词条背熟，也不保证永远在册。
  - id: part-02
    section: 曲折的线
    reference: 带往两边
    lyricText: 爱是一条曲折的线 将你我带往两边
    interpretation: >-
      爱不是直线相聚，是曲折的线把人带往两边——同一条线，方向却分裂。
      分开的两个人怎么都不能回到起点：几何上仍相连，拓扑上已回不去。
      比控诉更冷的是结构描写：不是谁剪断，是线本身把两端越拉越远。
    whyItMatters: 为副歌“两个世界”铺好空间模型。
  - id: part-03
    section: 字典无永远
    reference: 找不到永远
    lyricText: 在爱情字典里找不到永远 我们越走越远两个世界
    interpretation: >-
      歌名句：字典象征定义与掌控欲，偏偏“永远”这个词条缺失。越走越远、两个世界，
      是查阅失败后的地理后果。现场连唱里，这句常成为记忆钩——好听，也残酷：
      大家一起承认，最想查到的词查不到。
    whyItMatters: 标题落地；把伤感从个人命运抬到“定义失效”的层面。
  - id: part-04
    section: 输给时间
    reference: 要自己体验
    lyricText: 因为爱情输给时间 所以要自己体验 不管泪水多咸 有一天我会告别从前
    interpretation: >-
      失败归因给时间，而非单纯归咎对方；要自己体验，泪水多咸也得尝过，才谈得上告别从前。
      “新的感觉也许偶尔会出现 / 怎么没有了你都不对”夹在中间，说明身体与习惯比理智更慢退场。
      Start 舞台上，这是从集体伤感转向个人消化的段落：合唱减弱，叙述收回自己。
    whyItMatters: 给字典缺失之后的出路——不是重写词条，是独自体验并告别。
  - id: part-05
    section: 看不见的界限
    reference: 过不了那条线
    lyricText: 等到哭红双眼我才发现 爱情有一条看不见的界限 我们都过不了那条线 到另一边
    interpretation: >-
      发现来得太晚：哭红双眼之后，才看见爱情有条看不见的界限，双方都过不到另一边。
      不是差一步，是结构上不可逾越。现场版把这句唱满时，像给整晚偏甜的曲目撕开一道冷静的缝——
      有些关系的句号，是地理与词库双重到不了的对岸。
    whyItMatters: 收束比“找不到永远”更决绝：永远不仅缺席，界限还拦死对岸。

Start 演唱会里的《爱情字典》，是证书神话的反面教材。我已经学会爱情的语言，可是却失去你我的世界——技巧学满，世界仍散。爱是一条曲折的线，把人带往两边，分开后怎么都回不到起点。副歌冷冷查字典：找不到永远，我们越走越远，两个世界。

新的感觉也许偶尔出现，没有你却怎么都不对；因为爱情输给时间，所以要自己体验，不管泪水多咸，有一天告别从前。等到哭红双眼才发现，爱情有一条看不见的界限，双方都过不了，到不了另一边。现场把这首和《爱情证书》并置时特别清楚：一张想盖章证明不孤独，一本却承认最想查的词从来不在册。它不是教人绝望，是教人把“查无此词”也读成一种成年。
