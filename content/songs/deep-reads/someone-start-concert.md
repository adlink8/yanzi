Start 演唱会里的《Someone》，物料与录音室版同源，功能却换成「在被观看时唱被观看」。长发、改造令、镜中 freak 一出口，场内灯光立刻给第二面镜子：你不只是歌里的被改造者，也是台上的被凝视者。bing bang curly wurly 在体育馆里不再只是卧室复盘的口语碎片，而成为全场可听见的轻佻压力。

中段 Achilles 在现场常被拆行、拉长；记录稿中的 Still i won't wanna be / Someone who's answer to me，听起来比录音室「would / who'd」更像当场否决——偏不要成为别人指定的样子。解读以 start-live 文本为准，不必把差异上升成未经核实的改词史。副歌 sees like a child / gives like a saint / feels like an angel 短而亮，适合分层接唱，broken wings 与 fire remains 把破损与心火同时交给全场；曲末再叠一层品质清单，是 live 的确认仪式。真正防止它变成纯励志的，是床边空花瓶：越是体育馆，这句 collecting dust 越冷，把承诺落空的室内静物塞回狂欢节奏里。

对读站内 studio《Someone》时，不必争哪版「更正确」：一个贴着 bilingual 与 would 的室内伦理细读，一个贴着 Start 场次的 won't 与公开呼吸。现场版深读的重点，是身份宣言如何在舞台声学里既被放大成合唱，又不丢掉那瓶灰。
